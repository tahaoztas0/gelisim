# Contributing

Thank you for helping improve CityGML Audit!

1. Open an issue describing a bug, proposed feature, or reproducible test case.
2. Fork the repository and create a topic branch.
3. Keep changes small, document assumptions, and add regression tests.
4. Run `python -m unittest discover -s tests -v` locally.
5. Open a pull request explaining the change, limitations, and testing.

For bug reports, include CityGML version, Python version, a minimal sanitized XML example, expected output and actual output.

Please remove personal information, customer details, cadastral information, and confidential coordinates before submitting examples.

Contributors are expected to be respectful, constructive, and collaborative. See CODE_OF_CONDUCT.md.
