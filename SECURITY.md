# Security policy

**Supported version:** 0.1.x (best effort; early-stage project).

Please **do not** disclose sensitive security issues in a public issue. Use GitHub's private vulnerability reporting if available, or contact the repository maintainer privately through their GitHub profile. Include reproduction steps, affected versions and potential impact, but do not include private building files or client information.

This tool processes untrusted XML. Do not treat its output as a certification of data safety, legal compliance or standards conformance.
