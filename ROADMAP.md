# Roadmap

This is a proposed roadmap, not a claim of completed functionality.

- [x] Parse XML and detect malformed input
- [x] Detect duplicate GML IDs and basic ring issues
- [x] Provide CLI, JSON output, examples and unit tests
- [ ] Validate against selected official CityGML XSD versions
- [ ] Support CityGML 3.0-specific semantics
- [ ] Validate exterior/interior rings and polygon topology
- [ ] Validate file-level CRS consistency
- [ ] Add machine-readable SARIF reports
- [ ] Publish reproducible benchmarks with publicly shareable models
- [ ] Package releases and collect real adopter feedback

Contributions and real-world anonymized issue reports are welcome.
